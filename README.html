Ringkasan

Masalah yang dipecahkan

Membagi kelompok secara manual memakan waktu dan sering dianggap tidak adil. Kalau ada perubahan — mahasiswa pindah, kelompok dibubarkan — hasilnya harus dibuat ulang dari awal. Program ini mengacak pembagian, menyimpan setiap hasil sebagai arsip, dan memungkinkan hasil itu diubah di tempat.

Fitur

Yang bisa dilakukan

Empat operasi kelompok berjalan dari menu utama, plus data mahasiswa dibaca langsung dari file sumber.

01

Bagi kelompok

Acak urutan mahasiswa lalu bagi per kapasitas tetap. Pilih ukuran 3, 4, atau 6 anggota per kelompok.

02

Lihat kelompok

Pilih satu arsip, pilih nomor kelompok, lalu lihat daftar anggota beserta NIM dan nama.

03

Hapus kelompok

Hapus satu kelompok dari arsip. Nomor kelompok sisanya otomatis diurut ulang tanpa celah.

04

Ubah kelompok

Ganti nama atau NIM anggota di dalam kelompok. NIM duplikat ditolak otomatis.

Instalasi

Mulai dalam tiga langkah

Tidak ada dependensi eksternal — cukup Python 3 dan Git.

Clone repositori

Ambil kode dari GitHub ke mesin lu.

$ git clone https://github.com/AZZAMAF/System-Pembagi-Kelompok-CLI.git
$ cd System-Pembagi-Kelompok-CLI

Cek Python

Program butuh Python 3. Tidak perlu pip install — hanya modul bawaan (json, random).

$ python3 --version
Python 3.14.0

Jalankan

Penting: jalankan dari folder utama proyek, bukan dari dalam Code/. Path data/... di dalam kode bersifat relatif.

$ python3 main.py
Struktur

Letak file

Tiga file Python, satu file data mahasiswa, satu file menu, dan satu folder arsip.

Final_Project_CLI/
main.pymenu utama + routing pilihan
Code/grouping.pybagi, lihat, hapus, ubah kelompok
Code/menu.pycetak menu dari JSON
Code/processor_json.pypembaca file JSON
data/mahasiswa-cs.json36 mahasiswa (sumber)
data/menu-list.jsonlabel menu
data/Output/arsip hasil pembagian
Docs/PRD, brainstorming, panduan git
CATATAN

Data mahasiswa dibaca sekali saat import

grouping.py membaca data/mahasiswa-cs.json di level modul. Kalau file itu diubah di luar program, perubahan baru terbaca setelah program dijalankan ulang.

Menu

Lima pilihan

Label diambil dari data/menu-list.json, jadi bisa diubah tanpa menyentuh kode.

01 Bagi kelompok grouping_data()
02 Lihat Kelompok show_group()
03 Hapus Kelompok remove_group()
04 Ubah Kelompok update_group()
00 Keluar break
BATASAN

Ketik back untuk batal

Di update_group(), ketik back di langkah mana pun untuk kembali ke menu utama tanpa mengubah data. Langkah lain belum punya jalan batal — lihat bagian Status.

Status

Kondisi sekarang

Empat menu kelompok berfungsi dan sudah dipakai untuk membuat 9 arsip. PRD v5 masih memuat fitur yang belum dikerjakan — dicatat di sini supaya jelas mana yang sudah jalan dan mana yang belum.

Selesai

Bagi kelompok per kapasitas tetap

Ukuran 3, 4, atau 6 anggota. Acak lalu bagi, simpan ke arsip baru.

Selesai

Lihat kelompok

Pilih arsip dan nomor kelompok, anggota tampil dengan NIM dan nama.

Selesai

Hapus kelompok + nomor diurut ulang

Nomor kelompok sisanya dirapikan mulai dari 1 tanpa celah.

Selesai

Ubah nama / NIM anggota

NIM duplikat dicek ke seluruh kelompok sebelum perubahan disimpan.

Belum

Mode pembagian per jumlah kelompok

Saat ini hanya kapasitas. PRD meminta pilihan: jumlah kelompok, atau kapasitas maksimum.

Belum

Menu kelola mahasiswa (tambah, lihat, ubah, hapus)

Belum ada mahasiswa.py dan mahasiswa-kerja.json. Data sumber tidak pernah ditulis.

Belum

Validasi input angka

int(input()) tanpa try/except — huruf atau desimal membuat program berhenti.

Belum

Penomoran arsip otomatis

Nama file arsip diketik bebas oleh pengguna, jadi arsip lama bisa tertimpa.

Belum

Modul riwayat.py + skema arsip PRD

Belum ada id_grouping, mode_pembagian, kapasitas_anggota, belum_berkelompok.

Belum

Anggota tanpa kelompok

Setelah kelompok dihapus, anggotanya hilang dari arsip, bukan masuk daftar "belum berkelompok".

BUG

Program berhenti saat input bukan angka

Di grouping_data(), show_group(), remove_group(), dan update_group(), input dikonversi dengan int() langsung. Mengetik abc atau 3.5 membuat program berhenti dengan ValueError. PRD bagian 9 mensyaratkan program tidak crash untuk input tidak valid.
